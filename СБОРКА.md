# Сборка Sirius IDE

Как запускать из исходников и собирать установщик / portable.

---

## Требования

- **Node.js** 18+ (рекомендуется 20 LTS)
- **npm**
- **Windows** — основной целевой режим (`node-pty`)
- Для native-терминала: Visual Studio Build Tools (C++)

---

## 1. Разработка

```bash
npm install
npm start
```

- `npm start` → `tsc` в `dist/`, затем Electron.
- Native-терминал (опционально):

```bash
npm run rebuild:native
```

Проверки перед коммитом / релизом:

```bash
npm run test:ci
```

---

## 2. Компиляция main-процесса

```bash
npm run build
```

Точка входа: `dist/main.js` (`package.json` → `"main"`).

---

## 3. Дистрибутив (NSIS + portable)

Уже настроено через **electron-builder** в `package.json`.

```bash
npm run dist
```

Перед упаковкой автоматически идёт `predist` → `npm run test:ci`.

Результат в папке `release/`:

- установщик NSIS (`.exe`)
- portable-сборка

Иконка: `icon.ico` в корне. Лицензия MIT подключается в установщик.

---

## 4. Что попадает в пакет

Из `package.json` → `build.files`:

- `dist/**/*`, `renderer/**/*`, `package.json`, `icon.ico`, `LICENSE`, `README.md`
- runtime `node_modules` (dev-зависимости вырезаются exclude’ами)
- `asarUnpack` для `node-pty` / `*.node`

---

## 5. CI

GitHub Actions (`.github/workflows/ci.yml`): `npm ci` → `npm run test:ci` на push/PR в `main`.
